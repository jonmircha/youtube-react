## Cómo usar los códigos

Cada carpeta es un proyecto independiente: entra a la que quieras, instala sus dependencias y arráncalo.

```bash
git clone https://github.com/jonmircha/youtube-react.git
cd youtube-react/00-react-basicos
npm install
npm start
```

Las carpetas del curso (`00` a `09`) se hicieron con _Create React App_ y arrancan con `npm start`; las de _React Router_ 6, _Next.js_ y _Redux Toolkit_, con `npm run dev`. _Create React App_ ya está deprecado: para un proyecto nuevo usa _Vite_.
