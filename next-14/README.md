# Curso _Next.js_ 14

En esta carpeta encontrarás los códigos del [Curso de _Next.js_](https://www.youtube.com/watch?v=r5fkL5_rB70) de [Jonathan MirCha](https://jonmircha.com/): _App Router_, componentes de servidor y de cliente, rutas anidadas, dinámicas, agrupadas y paralelas, _layouts_, metadatos y una _API REST_.

