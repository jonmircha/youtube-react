# Curso _Redux Toolkit_

En esta carpeta encontrarás los códigos del [Curso de _Redux Toolkit_](https://www.youtube.com/watch?v=2_w3DnIKHxM) de [Jonathan MirCha](https://jonmircha.com/): el _store_ global, los _slices_ y sus _reducers_, `useSelector` y `useDispatch`, y un _CRUD_ contra una _API_ hecha con _JSON Server_.

```bash
npm install
npm run api   # la API de JSON Server, en el puerto 3001
npm run dev   # la aplicación, en otra terminal
```
