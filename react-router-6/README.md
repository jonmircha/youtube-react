# Curso _React Router_ 6

En esta carpeta encontrarás los códigos del [Curso de _React Router_ 6](https://www.youtube.com/watch?v=9w33u7hBWyk) de [Jonathan MirCha](https://jonmircha.com/): las diferencias con la versión 5, `Routes` y `Route`, `Link` y `NavLink`, rutas inexistentes, redirecciones con `Navigate`, paso de parámetros con `useParams` y `useNavigate`, rutas anidadas con `Outlet` y el uso de `HashRouter`.

```bash
npm install
npm run dev
```
